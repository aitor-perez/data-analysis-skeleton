# Slides template guidance

## Structure

- Beamer presentation.
- Sections: Context, Disclaimer, Data, Key Findings, Details, Conclusion.
- `institute: "EPFL"` in the YAML front matter can be changed.

## Placeholders to replace

- Title, subtitle, author, and institute in the YAML front matter.
- Bullet placeholder text.
- Disclaimer items.

## Notes

- Uses `preamble.tex` for Beamer formatting.
- Figures and tables can be included from analysis outputs.
