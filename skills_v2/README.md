# Data-analysis skeleton skills

Standalone skills for the data-analysis skeleton pipeline.

## Install

```bash
pip install -e .
```

## Skills

- `skeleton`: project orchestrator
- `build-duckdb`: build a DuckDB database from raw data
- `run-analysis`: scaffold and run an analysis against a DuckDB database
- `transform-data`: scaffold and run a data transformation or enrichment
- `render-quarto`: create and render Quarto deliverables
